# C3AI: A package for Crafting and Evaluating Constitutions for Constitusional AI
! Package under development

Make a new conda environment with:

`conda create -n c3ai python=3.10`

`conda activate c3ai`

`pip install torch==2.3.1+cu121 --extra-index-url https://download.pytorch.org/whl/cu121`

`pip install transformers accelerate datasets pandas numpy`

From the c3ai directory, run: 
`pip install -e .`
